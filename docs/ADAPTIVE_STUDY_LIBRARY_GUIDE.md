# Adaptive Study Library Guide

## Recommended Daily Workflow

1. Complete the official QAE block.
2. Copy the completed review output.
3. Open Practice Log and import the paste with a clear Session Label.
4. Review the preview counts.
5. Build the study package.
6. Open the lesson deck for a same-day retake or Smart Review.
7. Use the Master Missed Questions deck for targeted recovery.
8. Use Guild Study during a shared call.
9. Check Analytics weekly for due load, accuracy, lapses, and high-lapse cards.

## Deck Types

### Lesson Deck

One deck per unique imported session. It preserves the session's question set even when some questions already exist in the Master bank.

### Master QAE Question Bank

One deduplicated bank per scope. Every unique imported question is linked here automatically.

### Master Missed Questions

One targeted deck per scope. Questions answered incorrectly at import are linked here automatically.

### Original Deck

A manually created Personal, Guild, or Public deck. Public decks must use original content.

## Again / Hard / Good / Easy

- Again: failed recall; returns quickly and records a lapse when the card was already in review.
- Hard: correct with substantial effort; returns sooner than normal.
- Good: normal successful recall.
- Easy: immediate confident recall; receives a longer interval.

## Quiz Mode

Quiz Mode uses the imported question stem, all choices, correct answer, and available justification for each option. A wrong quiz answer records an Again review. A correct answer records a Good review.

## Guild Study

The Guild host selects a Guild deck and starts a synchronized session. Every member sees the same question, submits an individual answer, and then reviews the explanation together. Each person's personal review progress is saved separately.

## Dedupe Logic

The importer normalizes the question and choices and generates a stable fingerprint. The same question can belong to several lesson decks while existing only once in the scope's Master bank.
