# ControlQuest Studio v2.7

ControlQuest Studio is a Firebase-backed CISA study companion for individuals and study groups. v2.7 adds a complete adaptive Study Library built around user-imported QAE review sessions.

Start with `README_V2_7.md` for upgrade instructions, testing steps, and the Firestore data model.

Important: preserve your working `config/firebase-config.js` when upgrading, then publish the included `firebase.rules` in Firebase Console.
