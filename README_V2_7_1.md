# ControlQuest Studio v2.7.1

This update restores the original two-eye owl logo and refines the existing v2.7 workflow without changing the Firebase data model.

## Highlights
- Activity-based personal streaks with weekday/pause-block logic and automatic streak freezes.
- Daily Quests tied to QAE, adaptive review, and reinforcement activities.
- New daily Study Room checklist generated from the current date and roadmap topic.
- Automatic completed-week status, progress, and visual greying in Study Plan.
- Responsive Practice Log workspace.
- Full-screen animated game overlays, live sprint timer, animated hearts, Confidence Climb, and Guild Avatar Race.
- Functional Guild colors, icons, and optional image upload.
- Responsive calendar event modal.
- Revertible avatar previews that clear when leaving Rewards.

Preserve your working `config/firebase-config.js` when deploying.
